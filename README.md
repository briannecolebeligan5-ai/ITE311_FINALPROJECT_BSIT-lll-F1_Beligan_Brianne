# Vue Lab - Task Manager

**Student Name:** Brianne Cole Beligan
**Course and Section:** BSIT lll-F1

## Project Description
A to-do list web application that lets users add tasks, set priority levels, mark tasks as done, search and filter tasks, sort them by priority, and keep them saved even after refreshing the page.

## Technologies Used
- Laravel (PHP)
- Vue.js 3
- Vite
- HTML, CSS, JavaScript
- Browser localStorage
